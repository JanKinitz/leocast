# Leocast

Kindgerechte Web-App (PWA) für Kindermusik aus Spotify und Kinderpodcasts aus offenen Feeds – mit großen Bildern,
vollständigen Titeln und Offline-Modus. Privates Familienprojekt, nicht kommerziell.

## Entwicklung

```bash
npm install
npm run dev   # http://127.0.0.1:3000 (Spotify erlaubt kein "localhost")
```

Optional: `NEXT_PUBLIC_SPOTIFY_CLIENT_ID` setzen (Standard: Client-ID der Leocast-App).
